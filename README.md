# sentrywave.com

The Sentrywave company website, served by GitHub Pages from `master` at https://sentrywave.com.

## Editing

The pages are plain static HTML generated by one script. Products, companies, contact details and page copy are all in `_build/build.py`.

```
python _build/build.py
```

This rewrites every page plus `sitemap.xml`, `robots.txt`, `llms.txt`, `site.webmanifest` and `.well-known/security.txt`. Commit the generated files along with your edit. Pushing to `master` deploys.

Styles are in `assets/css/site.css` and the only script is `assets/js/site.js`. Images are in `assets/img/`: product screenshots in `products/`, payment and router logos in `partners/`, and the Sentrywave logo and icons in `brand/`.

`_config.yml` keeps `_build/` and this README out of the published site.
